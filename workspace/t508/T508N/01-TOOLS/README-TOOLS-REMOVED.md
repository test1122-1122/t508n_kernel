# Third-party Windows tools removed

This snapshot keeps the batch scripts and documentation, but the following
third-party binaries were removed during repository cleanup:

- adb.exe
- fastboot.exe
- AdbWinApi.dll / AdbWinUsbApi.dll
- Channel9.dll
- spd_dump.exe
- chsize.exe

Obtain them from the official Android platform-tools / SPD tool packages
before running the batch files.

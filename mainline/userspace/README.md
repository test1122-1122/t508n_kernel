# Userspace helpers

- `wifi-up.sh` — persistent WiFi bring-up
- `bluetooth-up.sh` — persistent Bluetooth bring-up
- `btattach_mini.c` / `btattach_mini` — static H4 attach helper
- `bluez/` — offline OpenWrt aarch64 BlueZ packages and installer
- `wpa.conf.example`, `hostapd-5g.conf.example`, `udhcpc.script`

Copy these to `/persist` and run from there.
